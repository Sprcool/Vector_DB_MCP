Reference

API reference

The MCP-facing surface of Vector_DB_MCP — one server, one tool.

MCP TOOL

search_knowledge_base

Registered on a FastMCP("Knowledge Base") server in mcp_server.py. Semantically searches the ingested document and returns ranked passages.

@mcp.tool()
def search_knowledge_base(question: str, top_k: int = 5):
    results = retrieval_service.search(question, top_k)
    return [asdict(result) for result in results]
INPUT

Request parameters

ParameterTypeDefaultDescription
questionstringrequiredA natural-language question. Embedded with the same model used for ingestion, then compared against the stored vectors.
top_kinteger5How many ranked results to return.
OUTPUT

Response schema

A list of plain dicts — one per result, ordered by ascending distance (closer = more relevant).

FieldTypeDescription
idstringSHA-256 content hash of the source chunk.
textstringThe retrieved passage text.
headingstringBreadcrumb of section headings the passage falls under, e.g. "Overview > Key Services".
pageintegerPage number in the source PDF (falls back to 0 if unavailable).
sourcestringSource filename.
distancefloatCosine distance from the query vector — lower is a closer match.

Notes

Empty collection

If ingestion hasn't been run yet, the collection exists but is empty — the tool returns an empty list rather than erroring.

No re-ranking

Results are raw vector-similarity order. There's no cross-encoder re-ranking step yet — see the roadmap.
