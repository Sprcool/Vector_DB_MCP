Getting started

From a clean clone to a working MCP-connected knowledge base.

BEFORE YOU START

Prerequisites

PyPython 3.10+

Required by Docling and sentence-transformers.

PdfA source PDF

Placed at Knowledge_Base/PDF_Source/, matching the filename in config.py.

McAn MCP client

Any MCP-aware client (e.g. Claude Desktop, Claude Code) to actually call the tool once the server is running.

Gb~1–2GB disk

For the embedding model weights and the local ChromaDB store.

SETUP

Installation & first run

  1. Clone the repository

    git clone https://github.com/Sprcool/Vector_DB_MCP.git
cd Vector_DB_MCP

  2. Create a virtual environment

    python -m venv .venv
source .venv/bin/activate   # .venv\Scripts\activate on Windows

  3. Install dependencies

    pip install docling sentence-transformers chromadb "mcp[cli]"

  4. Configure paths

    Open Knowledge_Base/Scripts/config.py and confirm PDF_PATH points at your source document, and that PDF_Source/ actually contains it.

  5. Run ingestion

    Parses, chunks, deduplicates, embeds, and stores the document. This populates Knowledge_Base/Vector_DB/.

    python -m Scripts.ingest

  6. Start the MCP server

    python mcp_server.py

  7. Connect an MCP client

    Point your MCP client's config at mcp_server.py so it can discover the search_knowledge_base tool. See the API reference for the tool's exact signature.

  8. Test search

    From the client, call search_knowledge_base with a question about your source document and confirm you get ranked results with headings and page numbers back.

TRY IT

Sample queries

Example questions to sanity-check retrieval quality once the server is running (phrased for the sample Azure Data Engineering brochure — adapt to your own source document).

“What is Azure Data Factory?”

A direct definitional question — should return the passage that introduces the service.

“How does the platform handle data pipelines?”

Tests semantic matching against a paraphrase, not an exact keyword match.

“What are the key benefits mentioned?”

Broader question — good for checking that top_k surfaces a diverse set of relevant passages.

“Which page discusses security and compliance?”

Checks that page/heading metadata on SearchResult is accurate and useful for citation.
