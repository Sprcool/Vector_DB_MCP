What's next

Future roadmap

Directions that would extend the pipeline beyond a single-document, single-shot retrieval system.

Retrieval quality

Hybrid search

Combine dense vector similarity with sparse keyword search (e.g. BM25) so exact terms and identifiers aren't lost to purely semantic matching.

Retrieval quality

Cross-encoder re-ranking

Re-score the top vector-search candidates with a cross-encoder before returning them, trading a little latency for meaningfully better ranking.

Query control

Metadata filters

Let callers scope search_knowledge_base by source, page range, or heading, instead of always searching the entire collection.

Ingestion

Incremental ingestion

Detect changed or added pages in a source PDF and re-ingest only those, instead of reprocessing the whole document every run.

Serving

Streaming responses

Stream retrieved context and generated answers incrementally through the MCP tool rather than waiting for the full result set.

Architecture

Agentic RAG

Let the calling agent decide when to retrieve, reformulate the query, and retrieve again — rather than a single fixed retrieval step per question.

Scale

Multi-document collections

Extend beyond one hardcoded PDF_PATH to an ingestible library of documents, each still traceable through source metadata.

Scale

Multimodal RAG

Extend chunking and embedding to cover tables, figures, and images extracted from source documents, not just prose text.
